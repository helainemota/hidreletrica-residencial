## Como duplicar e executar

Clone o repositório:

```bash
git clone https://github.com/helainemota/hidreletrica-residencial.git
cd hidreletrica-residencial
```

Instale o Flask:

```bash
pip install flask
```

Execute o programa:

```powershell
.\executar.bat
```

Acesse no navegador:

```text
http://127.0.0.1:5000
```
